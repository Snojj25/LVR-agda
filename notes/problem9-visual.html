Problem 9 — DPLL SAT-solver

Vizualni vodič: kaj počne vsak del kode v src/Solution.agda.

spremenljivke konflikt (unit propagation) pure literal iskanje (splitting)
1

Spremenljivke

na katerih indeksih bomo prirejali

Koda

lit-var : Literal → ℕ
lit-var (pos n) = n
lit-var (neg n) = n

dis-vars : Disjunct → List ℕ
cnf-vars : CNF → List ℕ

Kaj dela

  • lit-var — iz literala vzame številko spremenljivke (pos 3 in neg 3 → 3).
  • dis-vars / cnf-vars — zberejo vse indekse v klavzuli oz. celotni formuli.
  • Dvojniki so dovoljeni — iskanje jih kasneje preskoči.
2

Konflikt — unit propagation

zaznaj v celoti napačno klavzulo

Koda

lit-false? : Assignment → Literal → Bool
lit-false? ρ ℓ with eval-lit ρ ℓ
... | just false = true
... | _          = false

clause-conflict? ρ (lit ℓ)  = lit-false? ρ ℓ
clause-conflict? ρ (ℓ ∨d d) = lit-false? ρ ℓ and clause-conflict? ρ d

cnf-conflict? ρ (dis d)  = clause-conflict? ρ d
cnf-conflict? ρ (d ∧c φ) = clause-conflict? ρ d or cnf-conflict? ρ φ

Kaj dela

  • lit-false? — je literal pod ρ že false?
  • clause-conflict? — so vsi literali klavzule false? (klavzule ni več mogoče zadovoljiti)
  • cnf-conflict? — je katera koli klavzula v konfliktu?

To je jedro unit propagation: vejo, ki ubije neko klavzulo, takoj zavržemo.

3

Pure literal

ena polariteta → fiksna vrednost

Koda

cnf-pos? : ℕ → CNF → Bool   -- nastopa pozitivno?
cnf-neg? : ℕ → CNF → Bool   -- nastopa negativno?

pure-value : ℕ → CNF → Maybe Bool
pure-value v φ with cnf-pos? v φ | cnf-neg? v φ
... | true  | false = just true
... | false | true  = just false
... | _     | _     = nothing

Kaj dela

  • Pogleda, s kakšno polariteto se v pojavi v φ.
  • Samo pozitivno → just true.
  • Samo negativno → just false.
  • Mešano / je ni → nothing (ni pure, treba bo cepiti).

Pure literal lahko fiksiramo brez cepitve — drugje ne škodi.

4

Iskanje — splitting

tri medsebojno rekurzivne funkcije

Koda

data SatResult (φ : CNF) : Set where
  sat   : (ρ : Assignment) → eval-cnf ρ φ ≡ just true → SatResult φ
  unsat : SatResult φ

sat-search [] ρ φ with eval-cnf ρ φ in eq
... | just true = sat ρ eq
... | _         = unsat
sat-search (v ∷ vs) ρ φ with lookup v ρ
... | just _  = sat-search vs ρ φ
... | nothing = decide v vs ρ φ

decide v vs ρ φ with pure-value v φ
... | just b  = try-assign v b vs ρ φ
... | nothing with try-assign v true vs ρ φ
...   | sat ρ′ p = sat ρ′ p
...   | unsat    = try-assign v false vs ρ φ

try-assign v b vs ρ φ with cnf-conflict? (insert v b ρ) φ
... | true  = unsat
... | false = sat-search vs (insert v b ρ) φ

sat? φ = sat-search (cnf-vars φ) empty φ

Kaj dela

  • SatResult — sat ρ p nosi dokaz p; unsat = ni rešitve.
  • sat-search — glavna zanka; ob praznem seznamu ovrednoti formulo (tu nastane dokaz eq).
  • decide — pure literal (ena veja) ali cepitev (true, nato false).
  • try-assign — priredi v←b, a konfliktno vejo takoj zavrže.

Kako se faze povežejo (en korak iskanja)

sat-search (v ∷ vs)
Vzame prvo spremenljivko. Če je že prirejena → preskoči, sicer → decide.
lookup v ρ = just _ → preskoči, nadaljuj z vs
lookup v ρ = nothing → decide v vs ρ φ
decide
Izbere strategijo glede na pure-value.
pure → just b → try-assign v b (samo ena veja)
ni pure → poskusi v=true, če pade, še v=false
try-assign
Doda v←b v ρ in preveri konflikt.
konflikt → unsat (rez veje)
ni konflikta → sat-search vs (naprej)
sat-search []
Ni več spremenljivk → eval-cnf ρ φ.
just true → sat ρ eq (eq = dokaz)
sicer → unsat

Primer izvajanja

φ = (x₀ ∨ ¬x₁)   cnf-vars φ = [0, 1]

1
sat-search [0,1] [] φ → 0 ni prirejen → decide 0 …
2
pure-value 0 φ: 0 nastopa samo pozitivno → just true (pure!)
3
try-assign 0 true: ni konflikta → sat-search [1] [(0,true)] φ
4
pure-value 1 φ: 1 nastopa samo negativno → just false (pure!)
5
try-assign 1 false: ni konflikta → sat-search [] [(1,false),(0,true)] φ
6
eval-cnf ρ φ = (true ∨ ¬false) = just true
⇒ sat [(1,false),(0,true)] eq   (brez cepitve — oba literala sta pure)

V živo — korak za korakom

Izberi formulo in se sprehodi skozi algoritem. Literali se barvajo glede na trenutni ρ (true / false / nedoločen), klavzula v konfliktu pordeči, zadovoljena pozeleni.

Dokaz, ki ga nese sat ρ p

data SatResult (φ : CNF) where
  sat : (ρ : Assignment) → eval-cnf ρ φ ≡ just true → SatResult φ
Drugi argument p je dokaz te enakosti. Dobimo ga iz sat-search [] ρ φ with eval-cnf ρ φ in eq → sat ρ eq: ker se eval-cnf ρ φ zares izračuna v just true, je eq v bistvu refl. Spodaj je ta izračun.
